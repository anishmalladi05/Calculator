# Calculator
16 key calculator with a 128 by 32 pixel display and low profile choc switches. Uses circuit python. I made it to challenge myself and use a screen in my builds. I also wanted to try choc switches without building a whole keyboard.

## Assembly:
Look at the assembly video in the repo
<br></br>
Step 1:
<br></br>
Solder PCB components on
<br></br>
Step 2:
<br></br>
Assemble it into case according to the video

## Flashing:
To flash, press BOOT on the board, and while pressing boot, press reset, then release reset, and THEN release boot
<br></br>
Upload the UF2 File into the drive called RP1-RP2
<br></br>
Open the drive called CIRCUITPY
<br></br>
Delete everything in there
<br></br>
